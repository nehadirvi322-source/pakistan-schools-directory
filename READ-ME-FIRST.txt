IMPORTANT SECURITY NOTES:
- Only use a Supabase PUBLIC/PUBLISHABLE key (sb_publishable_...).
- NEVER enter sb_secret_, service-role, or passwords into config.js or GitHub.
- Only enter your password on the local sign-in form after you trust the files.
- The Supabase Data API must expose relevant tables, and is_super_admin RPC must be exposed for the admin permission check.
- Existing RLS policies must remain enabled and restrict administration using is_super_admin().
- The first test campus was UNPUBLISHED, so it will not show in the public directory.
- A locally saved connection setting in Safari only affects that browser. For a public deployment you must set the publishableKey in config.js, or configure the host to provide it. Publishable keys are public by design; secret keys are not.
- Do not publish real student information, private contacts, or unverified school information.
